FAQ

How do I know nothing is uploaded?

There is no server component at all. The app is a single HTML file with no analytics, no fonts and no CDN. You can disconnect from the internet and it behaves identically — and you can check the Network tab yourself.

Does it catch everything?

No regex tool catches 100%, and we won't pretend otherwise. It reliably catches structured data (emails, phones, ID numbers, card numbers, IPs, keys, tokens) plus context-marked Chinese names and addresses. It also reads JSON keys, so a field like "address": "…" is caught even without a 地址 prefix. For free-form names and unusual formats, add your own regex rule.

Can I get the original data back?

Yes. Every placeholder is recorded in a mapping table you can download as CSV. Paste it into the Restore tab with the AI's answer and the real values are put back. The mapping file never leaves your machine — delete it when done.

Will this make me compliant with GDPR / 个人信息保护法?

It reduces what you send to third-party AI tools, which is a useful technical measure. It is not legal advice and does not by itself make a processing activity lawful — talk to your DPO about purpose, basis and retention.

How is the license delivered?

A key like RL-XXXX-XXXX-XXXX arrives by email right after payment. Paste it into the app once; it is verified offline and stored locally. No login, no seat server, nothing to expire.

Can I use it at work?

Pro covers commercial use by the purchaser. Team covers up to 10 people in one organisation.
