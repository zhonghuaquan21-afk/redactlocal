## 一、发布前 5 分钟要做的事

| 事项 | 怎么做 | 为什么 |
|---|---|---|
| 主页简介 | 写「AI 数据脱敏工具｜主页置顶自取」 | 小红书正文不能放链接，简介和私信是唯一承接位 |
| 置顶笔记 | 先发一篇纯干货（本文案 B），把它置顶 | 新流量进来先看置顶，比看最新那条转化高 |
| 头像/昵称 | 用产品名或「XX 的 AI 工坊」这类可记忆的名字 | 用户是靠搜名字找回来的 |
| 私信自动回复 | 设一个关键词，比如"脱敏"→ 回一条带链接的消息 | 比一条条手回省事，也不容易漏 |

> ⚠️ 图和正文里**不要出现二维码、微信号、网址**。小红书对站外引流敏感，
> 轻则限流重则违规。承接全部走「主页简介 + 私信」。

## 三、正文（3 版，按账号阶段选一版发）

### 版本 A — 痛点故事版（新号首选，配图卡 1-4 全发）

```
上周差点出事。

同事为了赶一份投诉分析报告，把客服工单原样粘进了 ChatGPT。
工单里有客户姓名、手机号、身份证号、还有两笔订单的卡号后四位。

法务知道后只说了一句：这些数据不能再出现在第三方系统里。
但业务那边已经在等这份报告了。

后来我们这么解决👇

① 先在本地把敏感信息抹成占位符
   手机号 → [PHONE_CN_1]
   身份证 → [ID_CN_1]
   卡号   → [CARD_1]

② 拿干净的文本去问 AI，让它做归类、写回复

③ AI 回答里保留了占位符，再用映射表一键换回真名真号

整个过程数据不出电脑，断网都能用。
关键是第③步——很多人以为脱敏完就没法用了，其实能还原回来。

后来同事每天省了大概一个半小时。
报告照样准时交，法务那边也过了。

#AI效率 #数据安全 #办公工具 #ChatGPT #职场干货
```

### 版本 B — 干货清单版（收藏率高，适合置顶）

```
把客户数据交给 AI 之前，这 6 类信息必须先抹掉：

1️⃣ 手机号、邮箱
   最容易被导出的两类，也最容易被人拿去撞库

2️⃣ 身份证号
   18 位，中间 8 位就是出生日期，等于直接暴露年龄和生日

3️⃣ 银行卡号
   注意：16 位纯数字不一定是卡号，也可能是订单号
   Luhn 只作参考，打错一位也照样遮蔽（宁可多抹）

4️⃣ 中文姓名 + 地址
   "姓名：/客户/" 这类上下文能定位到
   纯粹散文里没上下文的姓名会漏，这个要人工再看一眼

5️⃣ 接口日志里的 API Key、Token、password=
   这不是隐私问题，是安全事故

6️⃣ IP 和内网地址
   很多人忽略这条，但内网拓扑泄露比手机号严重

顺序很重要：先脱敏，再问 AI，最后还原。
反过来（先问再改）就已经泄露出去了。

#数据安全 #AI工具 #职场技能 #效率工具
```

### 版本 C — 工具演示版（有基础粉丝再发，转化最高）

```
做了个小工具，解决一个很具体的麻烦：

每次想把工单、表格、日志丢给 AI，
都得先手动删一遍姓名手机号，删完还要检查有没有漏。

现在的方式是：
粘贴 → 勾选要抹的类型 → 复制 → 发给 AI

✅ 13 类信息，手机号/身份证/银行卡/邮箱/用户编号/密钥都能认
✅ 整张 CSV 也能批量处理，结构不变
✅ 占位符可还原，AI 写的回复能换回真名
✅ 单文件 13KB，断网能用，不上传

测了一下，一段 400 多字的工单，12 处信息一次全中，
包括银行卡号和我故意塞进去的 API Key。

免费版就能用，主页简介里。
#AI工具 #效率提升 #数据安全 #办公自动化
```

## 四、评论区话术（最关键的一环）

小红书 80% 的转化发生在评论区，不在正文。三种场景的说法：

**有人问"求链接/怎么用"**
> 主页简介里有～不用注册，直接打开就能用

**有人问"安全吗/会不会上传"**
> 打开后按 F12 → 网络 → 清空 → 开始脱敏，整个过程零请求。
> 更直接的办法：把网断了再试，行为完全一样。整页就一个 HTML 文件。

**有人质疑"正则肯定漏"**
> 对，纯散文里的姓名会漏，这个我写在说明里了。
> 结构化数据（手机号身份证卡号）是可靠的，名字建议人工扫一眼。

> 第三条不要辩解"我们很准"，直接承认边界。小红书上"敢说缺点"的评论区，
> 转化比"什么都好"的高——因为读者在找能信任的人，不是在找完美产品。

**置顶一条自己写的评论**，把最常见的问题先答了：
> 补充：免费版 5000 字够日常工单用，批量处理表格要专业版。
> 有具体漏检的例子可以发我，我加到规则里。

## 六、怎么判断这条行不行

| 指标 | 正常 | 好 | 不好怎么办 |
|---|---|---|---|
| 24h 曝光 | 200–500 | 2000+ | <150 说明封面/标题没吸引力，换标题重发 |
| 收藏率 | 3% | 8%+ | 低就是干货不够，改版本 B |
| 评论率 | 1% | 3%+ | 低就在正文结尾加一句提问 |
| 私信数 | — | — | 有私信但没成交 = 承接话术问题，改简介 |

曝光不行**别急着删了重发**（频繁删重发会降权），改标题、换首图，隔一天再发一版。

## 七、避坑清单

- ❌ 图上放二维码、微信号、外链 → 限流甚至违规
- ❌ 正文写"免费领取""白嫖""点击链接" → 判定营销
- ❌ 同一账号一天多篇同类内容 → 互相抢流量
- ❌ 私信里直接发长链接 → 容易被折叠
- ✅ 用"主页简介""私信我"承接，是最稳的方式
- ✅ 承认产品边界（漏检、只支持文本），反而更容易被信任
