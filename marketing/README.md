# marketing/ — legacy material

These files were produced while this was a paid product (Gumroad **$29** / 爱发电 **¥129**). The
project is now free and MIT licensed, so **everything in this folder is historical** and no longer
matches the shipping app:

| File | What it was |
|---|---|
| `landing-en.html` / `landing-cn.html` | Sales pages with the old pricing table |
| `SELLER-NOTES.md` | Build/packaging/licence-key runbook for the paid version |
| `LAUNCH.md` | 30-day go-to-market plan |
| `START-HERE.md` | Onboarding doc for the packaged deliverable |
| `content/` | Three SEO articles + one Chinese rewrite |
| `promo/` | Xiaohongshu (RED) card images and their HTML source |

Nothing here is loaded by the app. It is kept only as reference for anyone wondering how the
project got here — and because the articles in `content/` are genuinely useful technical write-ups on
PII detection that still stand on their own.

If you are looking for how to **use** or **contribute to** the project, see the top-level
[README](../README.md) instead.

The paid edition is discontinued. If you bought one: thank you, and the app is now identical for
everyone — the license key box has been removed and all features are unlocked.
